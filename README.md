# Homebrew Tap for bsnlib-cli (bsnlib.com)

Official Homebrew tap for **[bsnlib.com](https://bsnlib.com)** command-line tools.

## Installation

```bash
brew tap AbigailDavised/bsnlib
brew install bsnlib-cli
```

## Quick Test

```bash
bsnlib-cli --help
```

# BsnLib — Bassoon Heckel-System Fingering Chart & Acoustic Bocal Calibration Engine

Production command-line utility and Model Context Protocol (MCP) toolset for **[bsnlib.com](https://bsnlib.com)**. Features 4 full octaves of interactive Heckel-system fingerings, left-thumb 9-key mechanics, bocal pitch matching (#1, #2, #3), and contrabassoon sub-contra A transposition guides.
